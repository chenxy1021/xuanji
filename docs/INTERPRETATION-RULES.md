# 不依赖 AI 的「简单解读」需要什么

目标：同一张盘、同一份规则，永远输出同一段解读；不联网、不调模型，每条结论都能指回盘面字段。

现有盘面已经覆盖「事实层」。缺的是「事实 → 含义」的规则表和文案模板。

---

## 一、统一结构

每个体系加一个纯函数：

```python
# app/domains/<system>/rules.py
def interpret(chart: dict, *, level: str = "simple") -> list[Finding]: ...
```

```python
Finding = {
    "id": "bazi.daymaster.strong",
    "topic": "career",              # overview/career/wealth/love/health/...
    "tone": "neutral",              # positive/neutral/caution
    "statement": "日主庚金，生于巳月，火旺金相……",
    "evidence": ["day.gan=庚", "month.zhi=巳", "wuxing.火=2"],
    "refs": ["子平真诠·论十干"],     # 可选，公版或自撰
    "confidence": "rule",           # 规则命中，不是概率
}
```

前端只负责把 `Finding` 按 topic 分组渲染成卡片/段落。**规则没命中就不输出**，宁缺不编。

## 二、各体系需要的资料

### 1. 八字（优先级最高）

已有：四柱、十神、藏干、五行计数、神煞、大运、流年。

还需要：

| 资料 | 形式 | 说明 |
|---|---|---|
| 十天干/十二地支性情 | 22 条词条 | 每个字 3–5 个关键词 + 一段 40 字描述 |
| 十神含义 | 10 条 | 比肩/劫财/食神/伤官/偏财/正财/七杀/正官/偏印/正印 |
| 月令旺衰表 | 12×10 矩阵 | 日干在十二月令的旺相休囚死，用可配置分值 |
| 日主强弱规则 | 阈值 | 得令/得地/得势三项加权，给出「偏强/中和/偏弱」 |
| 五行缺失/过旺规则 | 5 条 | 缺某行、某行 ≥3 时的措辞，不下吉凶断语 |
| 十神组合规则 | 30–50 条 | 如「食神生财」「伤官见官」「官印相生」，每条含条件与措辞 |
| 神煞含义 | 现有 11+ 项 | 每项一句「传统上表示…」+ 免责 |
| 大运/流年引动 | 规则 | 大运干支与日主/月令的十神关系，只描述主题，不判吉凶 |

不需要：整本古籍原文。用公版书目（《子平真诠》《滴天髓》）的**观点摘要 + 自撰文案**即可，避免版权与玄学恐吓。

### 2. 紫微斗数

已有：十二宫、十四主星、辅星、庙旺、四化、大限。

还需要：

| 资料 | 形式 |
|---|---|
| 十四主星星情 | 14 条：关键词、落十二宫时的主题、庙旺/落陷的语气差异 |
| 辅星/煞星含义 | 现有 36 星，每颗 1–2 句 |
| 十二宫主题 | 12 条（命/兄/夫/子/财/疾/迁/友/官/田/福/父） |
| 四化含义 | 禄/权/科/忌 × 星曜，至少 4×14 的短语表 |
| 三方四正规则 | 本宫+对宫+两三合，现已能高亮，补「组合解读」规则 |
| 双星同宫 | 常见 20–30 组（紫府、日月、机巨……）的固定措辞 |
| 流派口径声明 | 中州派/倪师派差异，选定一种并写在页脚 |

若要做截图里的「典籍出处」，需要额外的**有授权语料 + 页码索引**；这属于 RAG，不是纯规则。

### 3. 西方占星

已有：十行星落座/落宫、上升/MC、相位、元素/模式计数。

还需要：

| 资料 | 形式 |
|---|---|
| 行星落座词条 | 10×12 = 120 条短句 |
| 行星落宫词条 | 10×12 = 120 条短句 |

占星最适合纯规则：数据最结构化，词条可以完全自撰。

### 4. 六爻

### 5. 梅花易数

已有：本卦/互卦/变卦、体用、生克、64 卦名与一句象意。

还需要：64 卦各 2–3 句主题文案；体用生克 5 种关系的固定措辞（已有判断，补文案）。

### 6. 孔明神卦

已有：签号、签级、卦爻、签文、基调/关键词/建议。基本可以直接出「简单解读」，只需把字段拼成 2–3 段并加免责。

### 7. 塔罗

已有：牌名、正逆位、牌阵位置、关键词。

还需要：78 张牌 × 正/逆位 = 156 条短义；牌阵位置含义；花色/元素对应。工作量最大的是文案，不是算法。

### 8. MBTI / 合盘

已有：类型名、summary、strengths、blind_spots、四维百分比；合盘有 matches/advice/disclaimer。**已经可以直接生成简单解读**，只差排版。

### 9. 奇门终身局

已有：三宫、九宫、门/星/神/干、生克、每宫 readings/summary。

还需要：八门/九星/八神各 8–9 条含义；十干克应表；宫位生克的固定措辞。现有 `readings` 已覆盖一部分。

## 三、共通资料（所有体系都要）

1. **措辞模板**：事实句 + 可能影响 + 建议 + 免责，四段式；禁止「必定/注定/大凶」。
2. **证据字段**：每条 Finding 必须带 `evidence`，前端可展开核对。
3. **流派声明**：八字子时换日、紫微四化表、奇门拆补/置闰、六爻空亡是否计入。
4. **中英文案**：规则文案也要有 `_en`，否则英文界面会退回中文。
5. **测试**：每个规则至少一个命中用例 + 一个不命中用例；同一盘重复调用结果一致。
6. **审校**：命理内容需要至少一位熟悉该体系的人过一遍措辞，避免把规则写成宿命论。

---

## 四、建议的落地顺序

1. **第一周**：定 `Finding` 模型 + 渲染组件；接 MBTI/孔明/合盘（数据已够）。
2. **第二周**：八字规则（旺衰 + 十神 + 五行缺失），先出 15–20 条可核对结论。
3. **第三周**：紫微（主星落宫 + 四化 + 三方四正）与占星（落座/宫/相位）。
4. **之后**：六爻/梅花/奇门；塔罗文案量大，可后置。

**不做什么**：不生成 0–100 分，不做健康诊断、投资建议，不用未经授权的书籍原文。
