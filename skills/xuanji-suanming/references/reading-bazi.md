# 八字怎么读

## 先看事实

读 Markdown/JSON 里的四柱表：年、月、日、时四组干支，以及日干（日主）。
十神列已经按日干算好；大运、流年、神煞也在同一份结果里。
**四柱、十神、大运方向与起运时间一律照抄，不重算、不改写。**

## 五步

1. **定日主**：日干是什么五行（甲乙木、丙丁火、戊己土、庚辛金、壬癸水）。
2. **看月令**：月支决定季节。先讲这个季节对该五行的支持或消耗，再谈其他三柱。
3. **数十神**：比劫、食伤、财、官杀、印，哪一类多、哪一类缺。多讲“力量集中在哪”，少讲绝对好坏。
4. **看关系**：天干五合、地支六合/三合/冲/刑/害。只讲结果表里出现的，不自己加。
5. **落到问题**：用户问事业就看官杀与财、问关系就看夫妻宫（日支）与财/官，问学业看印与食伤。

## 大运与流年

- 大运是十年一段的背景，流年是当年的触发点；先讲大运，再讲流年，不要反过来。
- 当前年份以 JSON 的 `liunian` 段为准；用户问某一年，就在表里找那一年的干支。
- 不预测具体事件（升职、结婚、生病），只讲“哪类主题更容易被推到台前”。

## 话术

- 好： “日主庚金，生在戌月，土金偏旺；十神里偏财透出，做事更看重实际回报。”
- 差： “你命里缺火，所以婚姻一定不顺。”——缺什么不等于凶，更不能推死结论。
- 好： “35–44 岁走戊寅，土生金、寅木动，适合把积累转成新项目；具体成不成看现实条件。”
- 差： “这步大运必发财。”

## 边界

寿元、生死、灾祸不谈；健康只讲作息与脏腑倾向，附“不适请就医”；
财运不给标的、不承诺收益；婚姻不劝离不劝生。
