# 排盘口径与工具说明

本技能自带排盘引擎（`scripts/chart-core.mjs`，由 ziwei-doushu 开源仓库的排盘内核打包而成），
**零外部依赖、不联网、不上传数据**，本机直接跑。运行时不用用户操心：`scripts/paipan.sh` 会自动找 Node（`$ZIWEI_NODE` → PATH → WorkBuddy 自带 `~/.workbuddy/binaries/node/`）。

---

## 一、起盘必须知道的四个输入

| 输入 | 为什么必需 | 缺失时怎么办 |
|---|---|---|
| **性别** | 男女大限顺逆、长生顺逆、小限顺逆全不同 | 必须问清，不能猜（猜错整盘错） |
| **历法**（公历/农历） | 农历与公历差一个月以上，排出来是两张不同的盘 | 用户说「我是 X 月 X」时必问一句「农历还是公历」 |
| **日期** | 定农历月日、五行局、紫微落宫 | 缺就停下来问 |
| **时间**（钟表时间或时辰） | 时辰决定命宫位置，差一个时辰十二宫全挪位 | 用户说不清时用「时辰区间反推」：问是「天刚亮 / 中午饭 / 天黑后」再匹配 |

**出生地是加分项不是必需项**：给了就做真太阳时校正（经度差 + 均时差），不给就按钟表时间定时辰并在盘面标注「未做真太阳时校正」。
北京时间下，经度每差 1° ≈ 4 分钟；出生时刻离时辰交界 5 分钟以内时，**有没有校正会改变时辰**——这种情况要提醒用户。

### 三个高频坑

1. **晚子时（23:00–23:59）**：按「子时换日」归到次日排盘，工具会自动处理并在输出里注明。用户明确要求「当晚子时算当日」时才用 `--shichen 子` 手工覆盖。
2. **闰月**：默认 `split`（月中分界，主流排盘口径）；倪师派「闰月作下月论」用 `--leap-policy next-month`。用户是闰月生人时必须说明用的是哪一派。
3. **说不清时间**：不要硬排一个时辰了事。先按上下两个时辰各排一张，比较后告诉用户「如果是 A 时，命宫在 X；如果是 B 时，命宫在 Y」，让用户用「哪个更像你」来定——这是传统上常用的定时辰法。

## 二、命令行

```bash
sh <技能目录>/scripts/paipan.sh \
  --name 张三 --gender male \
  --solar 1994-10-21 --time 08:45 --city 九江 \
  --out ./ziwei-charts
```

| 参数 | 说明 |
|---|---|
| `--gender male\|female` | 必填（也接受 男/女） |
| `--solar YYYY-MM-DD` | 公历生日（与 `--lunar` 二选一） |
| `--lunar YYYY-M-D` | 农历生日，配 `--leap` 表示闰月 |
| `--time HH:MM` | 钟表时间，走真太阳时 |
| `--shichen 子…亥` | 已知时辰，不做真太阳时校正 |
| `--city 九江` | 查城市经度做校正（内置全国城市库） |
| `--longitude 116.0` | 直接给经度，优先于 `--city` |
| `--leap-policy split\|next-month\|prev-month\|origin-month` | 闰月归属，默认 `split` |
| `--school QS\|XD1\|ZZ\|XD2` | 星曜亮度流派，默认 `QS`（《斗数全书》，主流排盘默认口径） |
| `--year 2026` | 指定流年（默认当前年），决定 `liunian` 段算哪一年 |
| `--out 目录` | 输出目录，默认 `./ziwei-charts` |
| `--json-only` / `--quiet` | 只出 JSON / 只打印路径 |

成功时终端会打印：盘面摘要（十二宫星曜）、识别到的格局、HTML 与 JSON 的绝对路径。
失败时以 `✗` 开头说明原因并以退出码 1 结束——**看到 `✗` 就不要继续解读**，把原因转述给用户。

## 三、产物

| 文件 | 用途 |
|---|---|
| `<姓名>-<日期>-紫微命盘.html` | 玄机纸墨朱砂版式命盘（4×4 外环十二宫 + 中宫信息与流年四化 + 格局总览 + 点击联动三方四正 + 日/夜切换），单文件、可打印、可直接发人 |
| `<姓名>-<日期>-紫微命盘.json` | 结构化盘面（含格局、十二神、小限、大限），**解读阶段的唯一事实来源** |

### 盘面上的几处标记

| 元素 | 含义 |
|---|---|
| 四边方位旁的三角（左绿←、右蓝→、底蓝↑） | 该宫对应的罗盘方位，纯装饰性标注 |
| 星名旁「小箭头 + 禄/权/科/忌」（绿/紫/蓝/红） | 该星**生年四化**的标记，箭头是四化符号，不是方位也不是运限指针 |
| 淡紫底色宫格 + 右上角 `25-34` | 当前大限所在宫与其虚岁区间 |
| 宫格右下「干支 + 宫名」 | 宫干宫支与宫名，身宫会多一个「身」标 |

### JSON 关键字段

- `core`：阴阳性别、五行局、命宫/身宫地支、命主/身主、虚岁、当前大限
- `palaces[]`：每宫 `branch / ganzhi / name / stars[{name,type,brightness,siHua}] / daXian / empty / borrowFrom`
- `liunian`：流年（`year / ganZhi / branch / palace / palaceStars / siHua[{hua,star,palace,branch}] / nominalAge`）——用户问「今年怎么样」时**只能**用这里的数据，不要自己推流年干支或流年四化
- 流年常用字段的完整路径：`liunian.ganZhi`、`liunian.palace`、`liunian.palaceStars`、`liunian.siHua[].star`、`liunian.nominalAge`
- `patterns[]`：识别到的格局（`name / level / palaces / description / conditions / source`）
- `lunar`：农历、年干支、节气四柱、非节气四柱
- `input`：原始输入与校正说明（含 `lateZiShifted` 是否发生晚子时换日）

`stars[].type` 语义：`major` 主星、`lucky` 吉星、`sha` 煞星、`minor` 杂曜。
`brightness` 为七档亮度（庙旺得利平不陷），`null` 表示该星在该宫不标亮度。

## 四、降级与故障处理

| 情况 | 表现 | 处理 |
|---|---|---|
| 没有 Node | 启动器报「没找到可用的 Node 运行时」 | 它已依次找过 `$ZIWEI_NODE`、PATH、WorkBuddy 自带运行时。依次让用户：① 退出 WorkBuddy 重开 ② 装 Node 18+（nodejs.org）③ `export ZIWEI_NODE=/路径/node`。**不要伪造盘面** |
| 日期不存在（2 月 30 日等） | `✗ 这个日期不存在` | 让用户核对生日，不要「顺延到下个月」自行修正 |
| 城市不在库 | `✗ 城市库里没有「××」` | 改用 `--longitude`，或改用 `--shichen` 只定时辰 |
| 时间说不清 | —— | 按上面「两个时辰各排一张」的办法处理 |
| 排盘抛错 | `✗ 排盘失败：…` | 原样转述错误，不猜测盘面，不手工拼一张盘 |

**绝不可以用「大概排一下」的方式绕过工具**：手写星曜位置几乎必错，错盘比没盘更糟。

## 五、盘面怎么读（讲给用户听时的用词）

- **十二宫**：命宫（自我）、兄弟、夫妻、子女、财帛、疾厄、迁移（外出与际遇）、仆役/交友、官禄、田宅（家与财库）、福德（精神享受）、父母。
- **三方四正**：本宫 + 对宫 + 两个三合宫。例：命宫的三方四正是命、财帛、官禄、迁移。
- **四化**：禄（顺与资源）、权（掌控与竞争）、科（名声与专业）、忌（执念与亏欠）。
- **亮度**：庙 > 旺 > 得 > 利 > 平 > 不 > 陷。庙旺＝能量足，陷＝能量弱，弱不等于坏。
- **大限**：十年一宫，虚岁起算；盘面右上角那个区间就是该宫的大限岁数段。
- **小限**：一年一宫，男顺女逆，盘面不显示岁数（在 JSON 的 `palaces[].xiaoXian`），只在用户问具体某年时用。
- **十二神**：长生 / 博士 / 岁前 / 将前四组，属辅助象，**不作为主要断语依据**，用户不问就不讲。
- **空宫**：无主星，借对宫主星论，力度打折，解读时必须声明「借星」。
