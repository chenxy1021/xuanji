# 六爻怎么读

## 先看事实

结果含：起卦方式、所问、起卦时刻、年月日干支、动爻、本卦/变卦/互卦三张表
（六神、六亲、卦画、纳甲、世应）。**卦名、动爻、纳甲、世应不得改动。**

## 取用神

按问题选一个“用神”，其余作为环境与过程：

| 问什么 | 用神 |
|---|---|
| 工作、职位、压力、官司 | 官鬼 |
| 钱、收入、投资、货款 | 妻财 |
| 学业、文书、房子、长辈 | 父母 |
| 子女、下属、宠物、解忧 | 子孙 |
| 同辈、竞争、合伙 | 兄弟 |
| 求测者本人 | 世爻 |
| 对方、环境、结果 | 应爻 |

## 五步

1. 定用神，看它在哪一爻、旺不旺（月日生扶还是克制）。
2. 看世应关系：世为自己，应为对方/事情；生合、冲克、比和分别讲顺、阻、平。
3. 看动爻：动爻是变量，老阳/老阴会变；动爻生用神为助，克用神为阻。
4. 看变卦：变卦是走向，互卦是中段过程；三者连起来讲“起—中—终”。
5. 回到问题给结论：能做/不能做/何时更适合，并给一个现实动作。

## 话术

- 好： “世爻在三爻兄弟，应爻在上爻；动爻化出妻财，说明这事先卡在人际，后面才见钱。”
- 差： “卦象大凶，千万别做。”——六爻讲条件与时机，不讲宿命。

## 注意

- 结果里明确写了“空亡未计算”，断卦时不要假装算过旬空。
- 一次只断一件事；同一事反复摇卦会得到互相矛盾的结果。
- 不预测生死、不诊断疾病、不替代法律与投资意见。
