# 合盘怎么读

## 先看事实

两种合盘都先分别列出甲乙双方的本命信息，再给“关系表”和参考分。
**双方四柱/命宫/夫妻宫/四化照抄；分数只是横向比较，不是判决。**

## 八字合盘

1. 看日主关系：相生、相克、相冲、比和，决定基本互动方式。
2. 看十神互看：甲方看乙方是什么、乙方看甲方是什么，讲彼此在对方生活里的角色。
3. 看夫妻宫（日支）：合、冲、刑、害，讲相处中的摩擦点。
4. 看五行互补：一方缺的、另一方多的，是否能补；不要把它说成“必须”。
5. 综合分只用来排序，不用来宣布“能不能结婚”。

## 紫微合盘

1. 先看双方命宫主星与夫妻宫主星。
2. 看星曜是否落入对方夫妻宫/命宫/福德宫，这是吸引与投射的来源。
3. 看四化飞入：禄/权/科/忌分别落到对方哪一宫，讲“带来什么”和“张力在哪”。
4. 空宫、无呼应时如实说“这组盘互动不集中”，不要硬编。

## 话术

- 好： “日主庚甲相冲，摩擦多出现在节奏与决策方式上；但五行上甲方缺火水、乙方有水火，
  长期相处能互补。”
- 差： “你们八字不合，趁早分手。”

## 边界

不劝分、不劝婚、不劝生；不评价第三方隐私；不把分数当命运。
合盘只讲结构差异与相处成本，最终选择在当事人。
