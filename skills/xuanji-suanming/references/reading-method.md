# 紫微斗数解读方法论（倪海厦《天纪》体系）

本文件是解读阶段的**唯一口径来源**。排盘事实以 `paipan.mjs` 输出的 JSON 为准，断语口径以本文件 + `quotes-ni.md` 为准。
两者冲突时：**盘面事实 > 断语口径**（不得为了凑成一句漂亮的话去改盘面）。

---

## 一、看盘顺序（五步，不可打乱）

### 第 0 步 · 先核盘面事实，再谈吉凶

开口第一段不是断语，是**复述盘面**：

> 「男，1994 年农历九月十七辰时，阳男土五局，命宫在午（廉贞天相），身宫在寅（紫微天府），生年四化：廉贞化禄入命、破军化权入迁移、武曲化科入官禄、太阳化忌入仆役。」

用户点头，后面的解读才成立。盘都认错了，断得再漂亮也是错的。**用户给出的出生信息与本盘不一致时，先停下来纠正输入，不要硬解。**

### 第 1 步 · 命宫与三方四正：定人格与「能不能成事」

- 命宫定**人格底色与人生主轴**；身宫定**后天发力点**（身宫落在哪个宫，那个领域就是他一辈子真正上心的地方）。
- 命宫必看三方四正：**命、财、官、迁**（本宫 + 对宫 + 两个三合宫）。命宫只说明「是什么人」，三方四正说明「能不能成事、靠什么成事」。
- 空宫（无主星）**借对宫主星**论，但要注明「借星」，且力度打折。
- 判断「能不能成事」看三方四正里**吉星与煞忌的比例、以及四化落点**，不看单颗星的名字。

### 第 2 步 · 生年四化：一生的主轴与缺口

四化是倪师体系的主力星，落宫就是「一生的力气花在哪、亏欠在哪」：

| 四化 | 核心含义 | 落宫时的读法 |
|---|---|---|
| 化禄 | 财源、顺遂、人缘、开始 | 落哪宫，那宫的事「来得顺、有资源」，也容易「不珍惜、过量」 |
| 化权 | 掌控、竞争、专业权威、性刚 | 落哪宫，那宫的事「要靠自己争、要担责」，过则霸道 |
| 化科 | 名声、考试、专业、才艺、贵人 | 落哪宫，那宫的事「靠专业与名声立身」，也主「慢、要熬」 |
| 化忌 | 执念、亏欠、想不开、事情的收敛点 | 落哪宫，那宫的事「一辈子反复卡在这里」，是功课不是判决 |

**化忌的落宫 = 这个人最放不下的地方**，也是解读里最该给出「怎么办」的地方（倪师：忌主「想不开」，解法是转念与选择时机）。

### 第 3 步 · 大限：命好不如限好

- 当前大限宫位 + 该宫星曜 + 该宫三方四正，**优先级高于本命好不好**。
- 十年为主、流年为辅。批十年讲「这十年的主题与代价」，流年只讲「今年在十年里的位置」。
- 大限宫若是本命的「凶宫」，不代表这十年一定坏，要看该宫有没有禄权科、煞星是否入庙。
- 未走到的大限不要提前细批，只讲方向。

### 第 4 步 · 格局与煞星：上限与破格点

- 吉格讲**上限与路径**（能到什么高度、靠什么到）。
- 煞忌讲**破格点**（在什么条件下会崩、怎么避开）。
- **吉处藏凶 / 凶处藏吉**（倪师原话，见摘编）：
  - 煞星**入庙** = 凶处藏吉。风险是看得见的，能防，反而平安。
  - 煞星**落陷**混在吉星里 = 吉处藏凶。没有预警，才是真的险。
  - 所以**不要见煞就说凶**，也不要见吉就说好，先看亮度。

### 第 5 步 · 落到「怎么办」

倪师的框架是 **命 1/3 + 运（环境/方位/时机）1/3 + 人事（念与做法）1/3**，后两者加起来大于天命。
所以每一条判断后面必须跟一个**可执行动作**，否则就是宿命论，不是这套体系的用法：

- 时机：什么时候宜进、什么时候宜守（对应大限/流年）
- 环境：适合的位置、行业性质、协作方式
- 人事：要改的做法与心念（倪师：改念 → 改做法 → 改命）

## 二、断语原则（写解读时必须遵守）

1. **一宫不孤断。** 任何结论至少要有两个独立来源互相印证（主星 + 三方四正 / 四化 / 大限 / 煞星），只有一个信号时只能说「倾向」，不能说「必然」。
2. **看「性」不看「职业表」。** 星曜讲性格与能量方式，不要机械对应职业清单；五行局不代表行业（倪师明确反对「水局就做水的行业」这种断法）。
3. **亮度定强弱。** 庙旺 = 能量足、表现外显；落陷 = 能量弱、内耗或延迟。**弱不等于坏**，要结合宫位与四化。
4. **六亲判断天然不可靠。** 父母、兄弟、子女宫的结论只能讲「关系模式与相处成本」，必须声明局限，不得下「你父母会早走」这类断言（倪师原话：「斗数批六亲本来就比较差一点」）。
5. **谈果不谈因。** 讲「什么时候、什么情境下会怎样、怎么应对」，不讲前世因果、不讲鬼神化解。
6. **不做宿命断言。** 不写「一定离婚」「注定无子」「活不过某岁」。改写为「这个配置在 ×× 上偏 ××，最容易在 ×× 情境下出问题，可做的调整是 ××」。
7. **引原话必须有出处。** 只能引用 `references/quotes-ni.md` 里真实存在的句子，并带上「讲次 + 时间」。**没有对应条目就不引**，不要编造名人原话。
8. **同一张盘，两次解读口径必须一致。** 星曜、宫位、四化、格局一旦从 JSON 读出，全程不得改动；不要在不同段落给互相矛盾的说法。

## 三、话题结构（按用户问什么选）

用户没有指定话题时，默认输出「命格总览」；用户问感情/事业/财运/健康/性格时，按对应结构输出。
每个话题的**骨架固定**（保证同一张盘每次输出结构一致），内容随盘变化。

- **命格总览**：命格定性 → 主星解读 → 三方四正 → 当前大限 → 优势与功课
- **感情婚姻**：感情格局 → 夫妻宫 → 三方联动 → 当前大限感情 → 实际建议
- **事业**：事业格局（宜任职/宜创业）→ 官禄宫 → 财帛联动 → 当前大限 → 方向建议
- **财运**：财运模式（主动财/被动财）→ 财帛宫 → 田宅（财库）→ 当前大限 → 理财建议
- **健康**：疾厄宫 → 需留意的方向（脏腑/作息）→ 大限走势 → 就医与预防提醒
- **性格**：命宫主星性格 → 三方综合 → 人际模式 → 优势与人生课题

详细输出格式见 `references/reading-templates.md`。

## 四、合规红线（违反即视为解读失败）

| 场景 | 不许做 | 改做 |
|---|---|---|
| 疾厄宫 | 下诊断、给治疗方案、劝停药或替代就医 | 只讲「留意方向 + 作息/情绪 + 该做的检查」，明确「有症状请就医」 |
| 财运 | 推荐具体股票/标的、承诺收益、劝加杠杆 | 只讲财路模式、节奏、风险偏好与守财能力 |
| 婚姻 | 劝离、劝生、断言克夫克妻、断生死 | 讲相处模式与成本、时间选择（何时宜婚）、沟通方式 |
| 寿元 | 预测死亡时间、断「大限将至」 | 完全不谈寿元；只谈某阶段要留意的健康与风险 |
| 他人隐私 | 未经同意解读第三人的盘 | 只解读本人或明确获授权者 |
| 化解 | 画符念咒、卖法器、改运服务 | 时机选择、环境调整、行为与心态改变（倪师本人反对法术化解） |

结尾固定附一句边界说明（见输出模板），但**不要用边界说明替代实质内容**——用户要的是可用的判断，不是免责声明。

## 五、把「盘面事实」翻译成人话的三个技巧

1. **星曜拟人化但不神化**：「廉贞天相在命」不是「你是贵人」，而是「你天生对秩序与体面敏感，讲规矩、也容易被规矩绑住」。
2. **用「场景」代替「形容词」**：不写「你财运不错」，写「你的钱多从专业与人脉来，靠承接项目或抽成比守着一份工资更顺；但现金流容易大进大出」。
3. **给选择，不给判决**：每段结尾给「宜 / 忌 / 观察点」三件具体的事，让用户能拿去用。
