# 解读输出模板

解读固定三段式：**核盘 → 正文（按话题骨架）→ 落地建议**。骨架不变、内容随盘变，这是同一张盘多次解读结论一致的前提。

---

## 一、开头：核盘（3–5 行，必须有）

```
【盘面确认】
男 · 1994 年农历九月十七 · 辰时 · 阳男 · 土五局
命宫在午（廉贞化禄、天相）· 身宫在寅（紫微、天府）
生年四化：廉贞化禄入命 / 破军化权入迁移 / 武曲化科入官禄 / 太阳化忌入仆役
```

- 星曜、宫位、四化、亮度一律来自 JSON，**一个字都不许改**。
- 若用户在起盘后补充或更正了信息，先说「按新信息重排，命宫从 X 变到 Y」，再往下讲。

---

## 二、正文骨架（按话题选一个）

### 1. 命格总览（默认）

```
【命格定性】     一句话给这个盘的核心气质与人生主轴
【主星解读】     命宫主星在此宫的意味（结合亮度与同宫星曜）
【三方四正】     财帛 / 官禄 / 迁移三宫如何联动，能不能成事、靠什么成事
【当前大限】     现在这十年的主题、机会、代价
【优势与功课】   两条天赋 + 一条要长期面对的功课
```

### 2. 感情婚姻

```
【感情格局】     一句话定性感情模式
【夫妻宫】       夫妻宫主星、四化、亮度，对关系的实际影响
【三方联动】     迁移 / 福德 / 子女等对感情的影响
【当前大限】     这十年感情走向与关键时间点
【实际建议】     何时宜定、择偶偏好、相处方式
```

### 3. 事业

```
【事业格局】     宜任职还是宜创业，一句话定性
【官禄宫】       主星、四化、亮度，适合的做事方式与专业方向
【财帛联动】     事业与财路的关系
【当前大限】     这十年事业节奏（进 / 守 / 转）
【方向建议】     行业性质、协作方式、要避开的坑
```

### 4. 财运

```
【财运模式】     主动财 / 被动财，钱从哪来
【财帛宫】       财富来源与流动特征
【田宅宫】       守财能力与不动产
【当前大限】     这十年财运节奏与风险点
【理财建议】     节奏、比例、忌做的事
```

### 5. 健康

```
【疾厄宫】       主星与煞忌，需留意的方向
【主要风险】     结合宫位对应脏腑与作息，讲「留意什么」
【大限走势】     这十年体力与压力节奏
【预防建议】     作息、情绪、该做的检查（不是治疗方案）
```

### 6. 性格

```
【命宫主星性格】 核心特质与内在矛盾
【三方综合】     财官迁对性格的加成与拉扯
【人际模式】     与人相处的默认方式与盲点
【优势与课题】   天赋优势 + 一生要修的功课
```

## 三、写法要求

1. **结论先行**：每段第一句是判断，后面才是依据。不要先铺垫一堆术语。
2. **依据可查**：每个判断后面括号标来源，如（廉贞化禄入命 · 命宫三方会武曲化科）。**JSON 里没有的东西不许写。**
3. **引原话要带出处**：只引 `references/quotes-ni.md` 里真实存在的句子，格式 `「…」（《天纪》7讲 00:31:19）`。**找不到就不引，绝不编造。**
4. **每段落到动作**：结尾给「宜 / 忌 / 观察点」，具体到时间、环境或做法。
5. **篇幅**：总览 600–900 字；单话题 400–700 字。宁可短而准，不要长而空。
6. **术语要让外行看懂**：第一次出现的术语（如「三方四正」「化忌」）用一句白话解释。

---

## 四、结尾：边界说明（固定，但只写一次）

```
（紫微斗数属传统命理，讲的是倾向与概率，不是定论；真正的走向仍取决于你的选择与行动。
以上健康部分仅为作息与留意方向的提醒，身体不适请就医；财务部分不构成投资建议。）
```

- 这段话放末尾，**不要放在开头**（开头放边界说明等于先免责再说话，用户会觉得在敷衍）。
- **不要**用「仅供参考」替代实质判断；也不要为了免责把话说成什么都没说。

---

## 五、绝对不要出现的写法

| 反面写法 | 为什么不行 | 改成 |
|---|---|---|
| 「你命中注定离婚」 | 宿命断言，且不可证伪 | 「这个配置在感情上容易××，尤其在××情境下；可做的调整是××」 |
| 「你会在 58 岁有大灾」 | 预测灾祸/寿元 | 「××大限要注意的是××，建议提前做的准备是××」 |
| 「你的疾厄宫显示你有肝病」 | 下诊断 | 「疾厄宫配置提示肝系统与作息是你要留意的方向，有症状请就医」 |
| 「买××股票 / 这只基金能赚」 | 投资建议 | 「你的财路偏××，节奏宜××，忌××」 |
| 大段罗列星曜名称和庙旺表 | 用户看不懂，等于没解 | 星曜只讲与结论相关的那几颗 |
| 把十二神、小限、杂曜堆满 | 噪音 | 用户不问就不讲 |
