## 一、设计立场（改版后）

上一版是「浅色刊物」，与用户给的目标图不符。新方向是**深色数据工作台**：

1. **近黑纸**：底色 `#0B0D10`，卡片 `#121417`，靠 1px 冷灰线（`#23272D`）分区，不用阴影。
2. **密度优先**：正文 13–14px，标签 11–12px，行高 1.7；一屏能读到「标题 + 图 + 三张卡」。
3. **单一强调色**：蓝 `#4A7CFF`，只用于选中态、图表、链接、主按钮。朱砂 `#E0705C` 只留给风险提醒。
4. **等宽数字**：干支、年份、评分、年龄全部 `font-variant-numeric: tabular-nums`。
5. **大面积留给标题**：首页仍保留大标题与留白，是唯一「不密集」的页面。

一句话：**从「可阅读的刊物」改为「可操作的工作台」，但保留中文衬线的骨相。**

## 三、Token（深色为基准）

```css
:root {                       /* 深色：默认 */
  --bg: #0b0c0e;
  --surface: #121417;
  --surface-2: #171a1e;
  --surface-3: #1d2126;

  --line: #23272d;            /* 1px 冷灰线 */
  --line-strong: #333941;

  --text: #e9ebee;            /* 14.9:1 */
  --text-2: #a6adb8;          /* 8.4:1  */
  --text-3: #6d7480;          /* 4.6:1，仅 11–12px 标签 */

  --blue: #4a7cff;
  --blue-hover: #6b94ff;
  --blue-soft: rgba(74, 124, 255, .12);
  --blue-line: rgba(74, 124, 255, .38);

  --risk: #e0705c;
  --risk-soft: rgba(224, 112, 92, .10);

  --radius-sm: 4px;           /* 输入框 */
  --radius-md: 6px;           /* 卡片、图表容器 */
  --radius-pill: 999px;       /* 胶囊 Tab、徽标 */

  --font-sans: -apple-system, "PingFang SC", "Noto Sans SC", "Microsoft YaHei", sans-serif;
  --font-serif: "Songti SC", "Noto Serif SC", "Source Han Serif SC", Georgia, serif;
  --font-mono: ui-monospace, "SF Mono", Menlo, Consolas, monospace;
}
```

浅色保留为切换项（`[data-theme="light"]`）：纸 `#F7F7F5`、卡 `#FFFFFF`、线 `#E4E4E0`、字 `#17181A`、蓝不变。

**用法纪律**

- 蓝色面积 < 10%（选中态、图线、主按钮、关键数字）。
- 朱砂只出现在「风险提醒」与四化「忌」，不用于普通强调。
- 分区一律用 `1px solid var(--line)`；**禁止投影**，浮层（下拉、弹窗）才允许 `0 12px 32px rgba(0,0,0,.5)`。
- 卡片圆角 6，Tag/胶囊 999，输入 4。

## 八、图表规则（硬约束）

**不允许** 0–100 分、不允许「综合评分」类编造数字。

| 体系 | 图 | 轴/维度来源 |
|---|---|---|
| 八字 | 五行雷达（5 轴）+ 十神分布条 | 雷达轴 = 木火土金水，值 = 天干 + 藏干计数（示例 2/3/3/2/1，最大 4）；分布条 = 十神出现次数 |
| 西方占星 | 元素分布 + 模式分布（饼/条） | 行星落座 → 火土风水、基本固定变动计数 |
| 紫微 | 宫位星曜强度条形 | 各宫主星数量 × 亮度档位（庙旺得利平陷） |
| 奇门 / 六爻 / 塔罗等 | 不画雷达 | 用结构列表或宫格，不造数 |

统一注脚：**「基于本盘数据，不是打分」**，11px，`--text-3`，紧贴图表下方 6px。

雷达绘制：5 轴从 12 点方向顺时针，环 4 圈（对应计数 1–4），填充 `rgba(74,124,255,.18)`，描边 `#4A7CFF` 1.5px，顶点 2px 圆点；轴标签 11px，数值 11px mono 放在标签下方。

## 十二、给前端的落地

1. token 直接替换：`--bg/--surface/--line/--text-*/--blue`；原 `--color-*` 可做别名映射，避免一次性改组件。
2. 结果页拆三块：`ResultTopBar`、`ChartRail`（slot：各体系盘面 + 周期 + 操作）、`AnalysisPanel`（Tab 容器 + 十个区块）。
3. 图表组件 `DataFigure`：`type: radar | bars | donut`，`data: {label, value, note}`，强制传 `note`，否则不渲染 —— 从组件层面阻止「编分数」。
4. 三卡组件 `InsightCards`：`items[]` 长度 0–3 自适应列数。
5. 周期 Tab 由 `chart.periods` 驱动（后端返回有哪些粒度），前端不硬编码。
