# 玄机 · unslop 设计规范

视觉来源：`design/unslop/home.html`（unslop by @heydamir · CC BY 4.0）。
本文件是全站改版的唯一判断标准；首页已按此落地，其余页面逐页对齐。

## 原则

- 纸、墨、朱砂；编辑排版；信息优先；可核对。
- 拒绝：渐变、玻璃拟态、霓虹色、大圆角、重阴影、图标块堆叠、营销式居中大标题、满屏卡片。
- 朱砂只用于「当前 / 重要批注」：当前导航下划线、选中项、命宫、关键数字。不铺大面积。
- 语义色（五行、四化、吉凶）保留在内容层，不进入普通 chrome。

## 色彩

- 浅色是默认（宣纸底 + 墨 + 朱砂）；深色是同一套系统的夜读覆盖，跟随系统或 Telegram，不另做配色世界。
- 背景 / 表面 / 文字 / 描边继续使用 `tokens.css` + `tokens-v2.css`。
- 普通交互（按钮、链接、选中态、焦点）改为墨色：
  - `--color-primary` 映射为 `--color-text`；
  - `--color-primary-soft` 用低对比墨色底（约 6–8% ink）；
  - `--color-primary-border` 用 `--color-border-strong`。
- `--color-accent`（朱砂）只做批注与当前态；`success / warning / danger` 保持语义。
- 「吉 / 正相 / 顺利」不再借用 primary，统一用 `--color-success`。

## 字体

- H1 / H2 / 盘面标题用 `--font-serif`，字重 400。
- 正文用 sans，16px / 1.8；标签 13–14px，辅助不低于 12px；数字用 tabular。
- 不再使用全大写加字距的 eyebrow / kicker；标签用正文字体、句式大小写。
- 桌面 display 56px / 1.28；移动 36px；h1 34→28px。
- 不使用 600 以上的 sans 大标题，不用全大写英文当主标题。

## 形状与组件

- 圆角 2–4px；除状态点外不用胶囊。
- 1px 细线分隔；除弹层外不用阴影；不用渐变背景。
- 主按钮：实心墨色，高 44px，2px 圆角；次按钮：透明底 + 1px 墨色描边，高 44px。
- 第三级动作（查看 / 删除 / 复制 / 全选）：文字 + 1px 下划线，保留 44px 热区；危险动作用危险色文字，不用色块。
- 开关用 2px 圆角方轨，不用胶囊。
- 输入框：surface 底、1px `--color-border-strong`、2px 圆角、48px 高；聚焦只加深描边，不做光晕。
- Chip：1px 描边、透明底、2px 圆角；选中用朱砂描边/文字，不用实心胶囊。
- 卡片：surface + 1px 线 + 4px 圆角，无阴影；能用分隔线就不要套卡片。
- 表格：只保留横向细线，无斑马纹，数字 tabular。

## 布局

- 容器 1280px；左右留白 20 / 32 / 48px。
- 桌面区块上下 48–96px，移动 32–56px；宁可留白，不要塞满。
- 分组头：`01` + 组名 + 数量，1px `--color-border-strong` 分隔。
- 移动端单列，保持 44px 触控热区，继续让开 Telegram 安全区。
- 起盘入口统一放在首页体系列表；顶部导航与底部 Tab 不再设「起盘」快捷项。

## 动效

- 140ms ease-out；hover 箭头右移 2px、颜色变亮；不做缩放、模糊、弹跳。
- 首页星盘是唯一的环境动效：缓转、星点呼吸、朱砂指针扫过；`prefers-reduced-motion` 下全部静止。

## 验收

- 所有页面在 390×844 / 1440×900、深/浅色、中/英文下无横向溢出、无重叠。
- `npm run build` 通过；`bash scripts/smoke-isolated.sh` 27/27。
- 对比度不低于 4.5:1；表单、图表、错误态、空态都可读。
