## 零、三条扩展原则

1. **结论先行**：占卜类（小六壬/梅花/六爻/塔罗）用户 80% 只看第一屏。结论卡永远在首屏，盘/卦/宫格一律下移。
2. **密度分级**：13 个入口是「导航密度」，命盘是「阅读密度」，九宫格是「信息密度」——三者用不同的字号/间距策略，不能一套尺寸套到底。
3. **不新增品牌色**：新体系靠**图标 + 命名 + 排布**区分，不靠颜色区分。朱砂仍只用于「忌 / 警示 / 关系冲突」这类需要被看见的少数点，全站占比 < 5%。

## 一、首页信息架构

### 1.1 分类与排序

14 个入口按「用户处在什么时间尺度上」分组，而不是按术数门类分组——门类对用户没有意义，场景才有。

| 分组 | 含义 | 体系（组内顺序） | 数量 |
|---|---|---|---|
| 命盘 | 一次性、看整体结构 | 四柱八字 · 紫微斗数 · 西方占星 · 奇门遁甲 · 大六壬 | 5 |
| 合盘 | 两个人之间的关系 | 八字合盘 · 紫微合盘 | 2 |
| 占卜 | 针对当下某个具体问题 | 六爻 · 梅花易数 · 小六壬 · 塔罗 | 4 |
| 运势 | 周期性、会反复回来看 | 日运 · 月运 | 2 |
| 趣味 | 轻量、社交传播 | MBTI 人格测试 | 1 |

组间顺序 = 使用频次从低到高、时间尺度从长到短：**命盘（一辈子一次）→ 合盘（一段关系）→ 占卜（当下）→ 运势（每天）→ 趣味（随手）**。

组内排序规则：`ready 在前 → 新上线 → 开发中`；同级按运营权重，权重在配置里维护，不写死在代码。

### 1.2 首页方案：常用 4 卡 + 分组两列宫格（采用）

**方案 A（采用）**

```
[品牌头]
[今日运势条 — 一行，可点进日运]
常用（4 个横排快捷卡，76×76）
  八字 | 紫微 | 合盘 | 日运
命盘 · 5
  [2 列宫格] 八字 紫微 占星 奇门 大六壬
合盘 · 2
  [2 列宫格] 八字合盘 紫微合盘
占卜 · 4
  ...
运势 · 2
  ...
趣味 · 1
[底部 TabBar]
```

**方案 B（不采用）：分组手风琴全折叠**
首屏只有 5 个组标题，点击才展开。

**为什么选 A**

- 14 个入口若做成整宽列表：14 × 64px ≈ 900px + 5 个组标题，超过两屏，中段入口最容易被划过去。
- 两列宫格把每个入口压到约 78px 高、171px 宽：图标可识别、名字不被截断、单组 2–5 个正好 1–3 行，整页约 1.5 屏。**新体系有曝光，老体系不用翻。**
- 折叠的代价是「多一次点击 + 新功能永远藏着」。方案 B 只在一种情况下成立：体系继续增长到 20+，那时把「趣味 / 更多」这 1–2 个组折叠即可，而不是全站折叠。

**具体规格**

| 元素 | 规格 |
|---|---|
| 常用卡 | 76×76，2×2 也可，圆角 14，图标 20 + 名称 13，`surface` + 1px `border` |
| 常用卡选择逻辑 | 最近 30 天使用次数 Top 3 + 固定 1 个「当前主推」；不足 4 个用默认补齐 |
| 分组标题 | 13px / 600 / `text-secondary` + 右侧计数 `text-muted` 11px，上下间距 16/8 |
| 分组宫格 | `grid-template-columns: repeat(2, 1fr); gap: 8px` |
| 宫格项 | 高 56–60px，横排：图标 32×32 容器 + 名称 13.5px + 状态点；整块可点，热区 ≥44 |
| 状态 | `ready` 无标记；`新` 用 10px 玄青字 + soft 底角标；`开发中` 整块 55% 透明 + 虚线边 + 右上角小字 |
| 折叠 | 仅对数量 > 5 且 `planned` 占半数的组提供「展开全部」，默认只显示前 4 个 |

### 1.3 今日运势条

首页顶部保留一条 64–72px 的「今日」横条：左侧干支（`庚午日 · 未时`），中间一句结论（`稳中有进`），右侧评分小环。点击直达日运页。它同时承担**回访理由**——每天内容都不同。

## 二、新组件规范

### 2.1 结论卡 `verdict`

所有占卜/合盘/测评结果页的第一块，统一结构：

```
┌─────────────────────────────┐
│ 结论 · 小六壬        [大安]  │   ← 11px 标签 + 状态 chip
│ 先阻后顺，守成得吉            │   ← 22px 衬线，最多两行
│ 口舌在前、落空在中、归静在后   │   ← 13px 次要色，一句依据
│ [宜守成] [忌强求] [吉时 申酉]  │   ← chip，最多 3 个
└─────────────────────────────┘
```

- 底：`--color-surface`；左侧 2px 玄青条（不是整块染色）
- 凶/忌类结论：仅把左侧 2px 与状态 chip 换朱砂，**标题不用红色**，避免制造恐慌
- 标题字号 22px（`--text-xl`），超过两行截断，详情走「展开」

### 2.2 双人信息卡 `pair-card`

合盘表单与结果页共用。

- 结构：一张卡内两段，每段 `48px 头像 + 姓名/称呼 + 生辰摘要 + 编辑`
- 中间分隔：1px 虚线 + 居中 24px 圆形「合」字印（`primary-soft` 底 + 主色字）
- 头像：40px 圆，`primary-soft` 底；男性用「乾」字、女性用「坤」，不画人像
- 必填缺失：整段降级为虚线框 + 「补全出生时间」，点击进入表单
- 结果页变体：在双人卡下方加**双盘对照表**（见 2.6）

### 2.3 评分条 `score`

两档：

**单值（结论级）**
```
契合度   78 / 100     同频互补
[████████████████░░░░]
```
- 数字 32px 衬线 + `/100` 11px；定性标签 13px（`高 ≥80 / 中 60–79 / 偏低 <60`）
- 条高 8px，圆角 pill，槽 `--color-bg-subtle`，填充 `--color-primary`
- 只有「风险类」评分（如冲突指数）才用朱砂，正向评分永远玄青

**多维（依据级）**
- 5 行：标签 60px + 条（4px）+ 数值 28px 右对齐，行高 32px
- 维度顺序固定：情感 / 沟通 / 价值观 / 生活节奏 / 财务观，便于跨次对比
- 条不做动画进出，仅在进入视口时从 0 长到目标值（240ms，一次）

### 2.4 九宫格 `palace9`（奇门 / 大六壬共用）

390px 宽下的硬约束：**不允许横向滚动**。

| 项 | 值 |
|---|---|
| 布局 | 3×3，`gap: 2px`，外框 1px + 圆角 12，间隙露出边框色形成网格 |
| 单宫尺寸 | (390 − 32 − 4) / 3 ≈ 118px 宽，最小高 104px |
| 内容层级 | 八神（11px muted）→ 九星（12px）→ 八门（14px / 600 / 主色或朱砂）→ 天干（13px 衬线） |
| 宫名 | 右下角 10.5px muted（巽/离/坤/震/中/兑/艮/坎/乾） |
| 中宫 | `bg-subtle` 底，内容居中：`中宫` + 天禽 + 局数 |
| 吉门/凶门 | 开休生 = 主色；死惊伤 = 朱砂；杜景 = 次要色。**只染「门」这一行** |
| 值符/值使 | 对应宫加 1.5px 主色内描边 + 角标「符 / 使」 |
| 点击 | 任一宫 → 底部详情抽屉（同紫微宫格交互），格内不放长文 |
| 字号下限 | 11px；关键信息（门、星）13px+ |

### 2.5 卦画 `hexagram`（六爻 / 梅花共用）

纯 HTML/CSS，不用图。

- 单爻：宽 44px、高 5px、圆角 2.5px
  - 阳爻：一段实线 `44×5`
  - 阴爻：两段 `18×5`，中间 8px 空隙
- 爻间距 6px，六爻总高 6×5 + 5×6 = 60px
- **自下而上**排列（初爻在最下），必须在左侧标 6 条细横线对齐的爻位数字（初/二/三/四/五/上）或用 6 个 1px 刻度示意
- 动爻：该爻右侧 12px 外放一个 6px 实心圆点（主色），并在爻位数字上标「○」
- 变卦：同尺寸灰化（`border-strong`），或用 0.6 透明度，放在本卦右侧、间隔 24px，中间一个 `→` 箭头
- 互卦：48px 缩放版（爻宽 32 / 高 4 / 间距 4），放在变卦下方
- 卦名：卦画下方 15px 衬线居中；上下卦名各 11px muted 分列两侧

### 2.6 双盘对照表 `duo-chart`

合盘结果页用，宽 358px 内不滚动。

```
        年柱   月柱   日柱   时柱
男 乾造  庚午   辛巳   庚辰   癸未
女 坤造  壬申   丁未   辛亥   癸巳
```

- 5 列：`32px + repeat(4, 1fr)`；行头 11px；干支 15px 衬线，干支之间不加分隔符
- 日柱列加 `primary-soft` 底（两行都加），标识「日主」这一最重要的对照位
- 差异高亮：**若后端提供冲合标记**，在对应格右上角加 4px 圆点（主色=合，朱砂=冲），图例在表下 11px；无该字段时只用表下文案说明日主关系，不要画空的图例

### 2.7 三宫链 `three-palace`（小六壬专用）

```
  月          日          时
[赤口] → [空亡] → [大安]
 口舌        落空        归静
```

- 3 列等宽，格间用 12px 的 `›` 连接（不用长箭头，省空间）
- 每格：宫名 15px + 五行/方位 11px muted + 一句 11px 注解
- 当前「时」宫加重：1.5px 主色描边 + 主色宫名；前两宫用 `bg-subtle` 弱化（原型已按此实现）
- 下方一行 11px 提示：「以时宫为主，月日为过程」——这是小六壬的读法，用户不知道

### 2.8 测评进度与选项（MBTI）

- 进度条：4px 轨道 + 主色填充，上方 11px「第 3 / 12 题」，不做百分比
- 题干：20px / 1.5 行高，卡内上下留白 24px
- 选项：两个全宽按钮，最小高 56px，左对齐 15px 文本，选中态 = 主色 soft 底 + 1.5px 主色边
- 底部：`上一题`（Ghost）+ `下一题`（Primary，未选时禁用 40%）
- 退出确认：返回时若已答 ≥1 题，弹「进度将不保存」

## 三、各体系结果页的信息层级

统一三段式：**结论 → 依据 → 细盘**。首屏（844 − 44 状态栏 − 52 顶栏 ≈ 748px）必须容纳「结论卡 + 至少 2 条依据」。

| 体系 | 结论（首屏第一块） | 依据（首屏下半） | 细盘（下移/折叠） |
|---|---|---|---|
| 八字合盘 | 契合度分 + 一句话关系定性 | 5 维评分、日主关系、夫妻宫对照 | 双盘对照表、大运同步、年月冲合 |
| 紫微合盘 | 契合度 + 关系定性 | 命宫/夫妻宫互照、四化互动 | 双盘十二宫对照、大限同步 |
| 小六壬 | 时宫吉凶 + 一句断语 | 三宫链（月→日→时）+ 每宫一句 | 六宫速查、宜忌时辰 |
| 梅花易数 | 本卦卦名 + 一句卦意 | 体用关系、动爻爻辞、变卦指向 | 六爻明细、互卦/错综卦 |
| 六爻 | 用神旺衰 + 吉凶断语 | 世应关系、动爻、月建日辰 | 六亲六神全盘、伏神 |
| 塔罗 | 牌阵核心牌 + 一句解读 | 关键 3 张牌位含义 | 全牌阵、正逆位细节 |
| 奇门遁甲 | 用神落宫 + 宜动宜静 | 值符值使、三奇六仪、门星神组合 | 九宫全盘、格局 |
| 大六壬 | 三传 + 一句课断 | 四课、贵神、天将 | 十二天将全盘 |
| 日运 | 今日评分 + 一句主题 | 事业/财运/感情/健康四维 | 时辰吉凶、宜忌、明日预告 |
| 月运 | 月度主题 + 评分 | 四个周期段落（上/中/下旬） | 关键日期、当月冲合 |
| MBTI | 四字母类型 + 类型名 | 四维倾向条、三条特质 | 维度详解、适配/留意、职业倾向 |

**首屏纪律**

- 结论卡高度 ≤ 180px，超出即说明写太长
- 任何「盘」不得出现在结论卡之上；奇门九宫格、紫微十二宫都属于「细盘」
- 首屏底部固定一条 44px 的「追问 AI」输入条（占卜类），让用户不用滑到底就能提问
- 加载中不要用骨架屏占位结论区——结论区用 88px 的定高占位 + 「正在起卦」，避免布局跳动

## 五、给前端的落地建议

1. **首页配置化**：把 14 个入口写成一份数组（`id / name / group / icon / status / weight`），分组顺序与组内排序由数据决定，不要写 14 个 `<div>`。新增体系只加一行配置。
2. **结论卡做成通用组件**：`<VerdictCard label status title desc chips tone>`，8 个体系复用；各体系只提供文案与 tone。
3. **九宫格与紫微宫格共用底座**：`<PalaceGrid :cols="3|4">`，仅列数与单元格模板不同；单元格内容用插槽。
4. **卦画组件**：`<Hexagram :lines="[0,0,0,1,0,0]" :moving="4" />`，`lines` 自下而上，1=阳。渲染就是 6 个 div，无需 SVG。
5. **评分条**：`<ScoreBar :value="78" label="契合度" />` 与 `<MetricRow>`，数值不要用 `width: 78%` 直接写，用 CSS 变量 `--v` 便于动画。
6. 新体系一律先接 `GET /api/v1/systems` 的 `status` 字段，`planned` 时前端只渲染禁用态，不要硬编码「开发中」文案。

## 六、原型说明（prototype-ext.html）

单文件、离线、390×844、沿用 `tokens.css`，顶部胶囊可切 9 屏 + 明暗主题。

| 屏 | 设计意图（一句话） |
|---|---|
| 首页分组 | 用「常用 4 卡 + 2 列分组宫格」把 14 个入口压进 1.5 屏，新体系不藏、老体系不翻。 |
| 合盘表单 | 双人卡把「两个生辰」收成一张卡，关系类型决定后续权重，减少一次选择成本。 |
| 合盘结果 | 首屏先给 78 分契合度和五维条形，双盘对照表下移，让「像不像」先于「为什么」。 |
| 小六壬 | 结论卡 + 三宫链三段式，把「月日时为过程、时宫为结果」的读法直接画出来。 |
| 梅花 | 六条 CSS 爻线自下而上、动爻打点、本卦→变卦并排，卦象本身就是首屏结论。 |
| 奇门九宫 | 3×3 在 390px 内不滚动，只染「门」一行，值符值使靠描边而非颜色区分。 |
| 日运 | 一个环 + 一句主题 + 四维短条，30 秒读完，为「每天回来看」设计。 |
| MBTI 测评 | 一屏一题、进度可感知、选项整块可点，答题过程不出现任何干扰。 |
| MBTI 结果 | 四字母 + 四条倾向条，先给身份认同，再给解释。 |

> 数据说明：首页/合盘/日运/奇门中的干支取自真实排盘样例（1990-05-15 14:30 男 / 1992-08-03 09:20 女 / 2026-11-20），小六壬与梅花按通行起课规则手算，奇门局数为示意，仅用于版式验证。
