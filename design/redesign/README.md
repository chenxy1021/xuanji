# 界面重设计 · 样稿（2026-11）

`index.html` 是可直接双击打开的单文件样稿，覆盖五个桌面屏与一屏移动端：

| # | 屏 | 路由 |
|---|---|---|
| 01 | 首页 | `/` |
| 02 | 起盘 | `/chart/bazi` |
| 03 | 结果 | `/result?id=…` |
| 04 | 记录 | `/history` |
| 05 | 设置 | `/settings` |
| 06 | 移动端首页 | 390 × 844 |

盘面、大运、记录条目均为示例数据，只用于看版式与层级。

## 方向

纸、墨、朱砂的编辑式工作台：更暖的宣纸底、更稳的墨色、更少的容器。信息靠位置与字号分层，不靠阴影和色块；一屏只保留一个视觉焦点，朱砂只做批注（导航当前项、盘心印章、引用线）。

## 令牌

| 角色 | 值 | 用途 |
|---|---|---|
| paper | `#f6f3ec` | 页面底 |
| paper-2 | `#ece7db` | 画板底、弱填充 |
| surface | `#fffdf8` | 卡片、表单 |
| ink | `#23211b` | 主文字、主按钮 |
| ink-2 | `#555048` | 次文字 |
| muted | `#676154` | 提示、标签（对 paper 5.6:1，对画板底 4.7:1） |
| rule | `rgba(35,33,27,.14)` | 细线 |
| rule-strong | `rgba(35,33,27,.30)` | 强分隔 |
| coral | `#b4402f` | 唯一强调色 |
| sage | `#4f7a57` | 仅成功状态点 |

字体：标题 `Noto Serif SC`（Latin 用 `Instrument Serif`），正文 `Geist` + `Noto Sans SC`，数字与标签 `Geist Mono`。

字号下限：正文 16px，说明文字不小于 12px，功能标签、表头、导航不小于 13px；不再使用 8.5–11px 的微型字。

## 每屏改动

- **首页**：卡片墙 → 编号索引（体系可扫读）；首屏加唯一主行动；星盘保留为唯一动效。
- **起盘**：说明与表单同屏；细线分组、下划线输入；主按钮只留一个。
- **结果**：盘面 / 事实 / 解读三段式；事实为 1px 网格；朱砂只出现在印章与引用线。
- **记录**：卡片列表 → 细线表格；时间与盘面摘要用等宽数字；删除默认弱化。
- **设置**：左侧目录 + 分区标题统一为衬线 19px；AI 配置去掉盒子，改为标签 + 输入。
- **移动端**：首屏保留标题、星盘、第一组体系；导航收进底部标签栏。
